# Cosmos Case Study for CoBRa

The scripts from query_cosmos_participation_rate.py and query_cosmos_volume.py use the quicknode endpoints.
To reproduce the data, sign up for a free account on quicknode and create a cosmos api endpoint link.
Create an apikeys.py file and put the link into an api_keys = [] array to run the scripts.
The participation rate data is also already on here in the output.txt and the stats used in the paper are calculated in processdata.py
